<threat_model>
ASVS Level 1 Threat Model:
1. Threat: Unauthorized state tampering via `set_ready` frame outside lobby state or by non-members.
   - Severity: High (Mitigated).
   - Mitigation: Server dispatch verifies that the room code exists, room state is strictly `"lobby"`, and the sending `playerId` exists as an active player in that room before mutating `player.isReady`.
2. Threat: Pre-start race cheat / early typing during countdown sequence.
   - Severity: High (Mitigated).
   - Mitigation: Countdown UI presentation is synchronized via NTP offset (`startsAtServerMs - clockOffsetMs`), but race start enforcement is strictly server-authoritative. Keystrokes sent before `startsAtServerMs` are immediately rejected with error code `RACE_NOT_STARTED` (Phase 2 anti-cheat check #2).
3. Threat: Input validation bypass / unexpected enum injection on passage filters.
   - Severity: Medium (Mitigated).
   - Mitigation: Filter types (`PassageLengthFilter = "all" | "short" | "medium" | "long"`) are strongly typed and validated client-side against the immutable bundled `PASSAGES` corpus.
</threat_model>

1. Refactor `apps/web/src/components/CountdownView.tsx` per D-14 and UI-SPEC resolved consideration (loading: Countdown Overlay):
   - Props: `startsAtServerMs: number`, `onCountdownComplete?: () => void`.
   - Retrieve `clockOffsetMs` from `useClockStore((s) => s.offsetMs)`.
   - Time calculation: on each animation frame or high-frequency interval (16ms):
     - `serverNow = Date.now() + clockOffsetMs`.
     - `remainingMs = Math.max(0, startsAtServerMs - serverNow)`.
   - Digits & state transitions:
     - `remainingMs > 2000 && remainingMs <= 3000`: displays `"3"`.
     - `remainingMs > 1000 && remainingMs <= 2000`: displays `"2"`.
     - `remainingMs > 0 && remainingMs <= 1000`: displays `"1"`.
     - `remainingMs <= 0`: displays `"GO!"` and triggers fade out.
   - Motion blur and scaling animations:
     - Digits styled with Display 48px font (`text-6xl font-bold font-mono text-sunlit-clay-400 drop-shadow-[0_0_20px_rgba(204,103,34,0.6)]`).
     - CSS transition scales digits from `scale-125 blur-sm` down to `scale-100 blur-0` over 300ms on each second tick.
   - Overlay container:
     - Fixed or absolute overlay centered above track (`inset-0 flex items-center justify-center bg-black-forest-950/70 backdrop-blur-xs z-30 transition-opacity duration-300`).
     - When `remainingMs <= 0`, opacity transitions to 0 over 300ms before unmounting.
