<objective>
Implement the complete graceful disconnect UX: 60s grace period on socket close, real-time `player_disconnected` and `player_reconnected` broadcasts to opponents, opponent waiting notification UI, and 60s eviction timeout with host migration.

Purpose: Fulfill REQ-07 success criteria 1 and 4 (opponents see 'X disconnected' not 'X joined/left', 60s reconnect grace, clean eviction).
</objective>

<tasks>

### Task 1: Wire schemas & broadcast helpers for disconnect/reconnect events
- In `packages/shared/src/messages.ts`:
  - `playerDisconnectedSchema = z.object({ type: z.literal("player_disconnected"), playerId: z.string().uuid(), nickname: z.string(), timeoutMs: z.number().int() })`
  - `playerReconnectedSchema = z.object({ type: z.literal("player_reconnected"), playerId: z.string().uuid(), nickname: z.string() })`
  - Add both to `serverToClientSchema`.
- In `apps/server/src/ws/broadcast.ts`:
  - Implement `broadcastPlayerDisconnected(room: Room, player: Player, timeoutMs: number): void`.
  - Implement `broadcastPlayerReconnected(room: Room, player: Player): void`.

### Task 2: Server 60s disconnect grace period & ticker eviction
- In `apps/server/src/race/types.ts`:
  - Add `disconnectedAt: number | null` to `Player` interface.
- In `apps/server/src/ws/handlers.ts`:
  - On `close(ws)`:
    - Look up room and player.
    - If room is in active state (`racing`, `countdown`, `grace`, or `lobby` with >=2 players):
      - Set `player.disconnectedAt = Date.now()`.
      - Call `broadcastPlayerDisconnected(room, player, 60_000)`.
    - If room is empty or only 1 player in lobby: remove immediately.
- In `apps/server/src/race/controller.ts`:
  - In `tick()`:
    - Check players with `disconnectedAt !== null`.
    - If `now - player.disconnectedAt >= 60_000`:
      - Call `removePlayer(room.code, player.playerId)`.
      - Broadcast `player_left`.
      - If room has 0 players left, delete room.
- On `rejoin_room`:
  - Clear `player.disconnectedAt = null`.
  - Call `broadcastPlayerReconnected(room, player)`.

### Task 3: Client UI notifications & opponent status
- In `apps/web/src/App.tsx`:
  - Listen for `player_disconnected` and `player_reconnected` events.
  - Display a temporary floating toast / notification:
    - "Player [Nickname] disconnected — waiting up to 60s..."
    - "Player [Nickname] reconnected!"
  - Dim or show an offline indicator next to disconnected player's cursor / progress bar in `RaceView`.
</tasks>
