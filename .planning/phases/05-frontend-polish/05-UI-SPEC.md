## Visual Hierarchy & Focal Point

### Primary Screen Focal Point
The centered race track (760px–800px fixed-width container) with the active word, local typing caret (`#CC6722`), and the leading opponent caret with its glowing ghost wake serves as the unambiguous primary visual anchor.

### Visual Hierarchy (3 Levels)
1. **Level 1 — Primary Focal Layer**:
   - Active typing word under the local caret.
   - Local player's caret (z-index: 20, 2px wide, Sunlit Clay `#CC6722` glow).
   - Race leader's opponent caret (z-index: 10, pastel glow, leader ghost wake trail).
2. **Level 2 — Secondary Support Layer**:
   - Live Race HUD directly above track (large 24px Net WPM integer, current rank badge "#1", progress bar).
   - Opponent name micro-tags floating above carets (`[Alice]`, `[Bob]`).
   - Synced countdown overlay digits (Display 48px) during start sequence.
3. **Level 3 — Tertiary Context Layer**:
   - Passage container card background (`#15180C`), Olive Leaf borders (`#3C4626`), and deep canvas (`#12190B`).
   - Pending passage text (`#7D4D0F`).
   - Room code indicator and copy invite link control.

### Icon Accessibility
All icon-only and graphic triggers include explicit accessible labels:
- `🎲` Randomize Passage: `aria-label="Pick random passage"`
- `📋` Copy Link: `aria-label="Copy room invite link"`
- `✖` Dismiss Toast: `aria-label="Dismiss notification"`
- `🥇🥈🥉` Podium Medals: `aria-label="1st Place"`, `aria-label="2nd Place"`, `aria-label="3rd Place"`
