<objective>
Implement graceful SIGTERM shutdown: on shutdown, immediately notify all connected clients, stop accepting new room joins/race starts, let active races finish naturally, and exit once drained or after a 90s hard cap (D-01, D-02, D-03).

Purpose: Phase 7's ad-hoc SIGTERM handlers call `.stop()` and exit immediately today — any in-flight race is silently killed. This plan makes shutdown safe for players mid-race without touching the deploy config that will eventually enforce it (fly.toml is explicitly out of scope this phase — see README task in 06-03).

Note on source grounding: 06-CONTEXT.md's canonical_refs cites `apps/engine/src/race/validator.ts` — that file does not exist in this tree (`git ls-files` confirms). The real anti-cheat file is `apps/engine/src/race/validate-keystroke.ts`; that correction only matters for Plan 06-03 (this plan does not touch it).

Output: EngineWorker.drain(), GatewayInstance.drain(), the `draining`/`drained` EventBridge contract, a new SERVER_SHUTTING_DOWN error code with a client-side toast, and drain regression tests in both apps/engine and apps/gateway.
</objective>
