<threat_model>
ASVS Level 1 Threat Model:
1. Threat: Malformed or oversized WebSocket payloads causing Gateway denial of service or crashing the process.
   - Severity: High (Mitigated).
   - Mitigation: Inbound WS messages are validated with `clientToServerSchema.safeParse`. Payloads failing schema or JSON parsing are logged and dropped without terminating the socket or propagating down to the Engine.
2. Threat: Room-creation flooding / socket resource exhaustion by malicious IPs.
   - Severity: High (Mitigated).
   - Mitigation: `ipRateLimiter` enforces a strict 10 room creations per hour cap per client IP address. Exceeding the threshold immediately rejects with an error frame without creating state in Engine.
3. Threat: Ghost sockets remaining open indefinitely after network partition.
   - Severity: Medium (Mitigated).
   - Mitigation: Gateway runs a 15-second heartbeat ping with a 5-second pong timeout. Dead or unresponsive connections are terminated by Gateway and `client_disconnected` is published to Engine.
</threat_model>

<action>
1. Create `apps/gateway/src/ws/client-manager.ts`:
   - `ClientManager` class:
     - `sockets: Map<PlayerId, ServerWebSocket<WsData>>`.
     - `roomMembers: Map<RoomCode, Set<PlayerId>>`.
     - `addSocket(playerId: string, ws: ServerWebSocket<WsData>): void`.
     - `removeSocket(playerId: string): void`.
     - `assignRoom(playerId: string, roomCode: string): void`.
     - `clearRoom(playerId: string, roomCode: string): void`.
     - `getSocket(playerId: string): ServerWebSocket<WsData> | undefined`.
     - `getRoomSockets(roomCode: string, excludePlayerId?: string): ServerWebSocket<WsData>[]`.
2. Create `apps/gateway/src/ws/handlers.ts`:
   - Define typed `WsData`: `{ playerId: string; roomCode: string | null; ip: string; lastPingAt: number; clientOffsetMs: number; }`.
   - Implement Bun.serve `websocket` hooks:
     - `open(ws)`: allocates `playerId` via `nanoid()`, registers in `ClientManager`, notifies `bridge.publishToEngine({ type: "client_connected", ... })`.
     - `message(ws, msg)`: passes to `dispatch(ws, msg, bridge, clientManager)`.
     - `close(ws, code, reason)`: unregisters from `ClientManager`, notifies `bridge.publishToEngine({ type: "client_disconnected", ... })`.
     - Heartbeat ping ticker: sends ping every 15s, closes sockets with no pong within 5s.
3. Create `apps/gateway/src/ws/dispatch.ts`:
   - Parses raw frame text with `try/catch`.
   - Validates via `clientToServerSchema.safeParse`.
   - Handles `ping` directly at gateway level (replies with `pong`).
   - If `create_room`: enforces `ipRateLimiter.check(ws.data.ip)`. If exceeded, sends error frame `RATE_LIMITED`.
   - Forwards valid game frames (`create_room`, `join_room`, `leave_room`, `set_ready`, `start_race`, `keystroke`, `rejoin_room`, `rematch`) to Engine:
     `bridge.publishToEngine({ type: "client_message", playerId: ws.data.playerId, roomCode: ws.data.roomCode, ip: ws.data.ip, clientOffsetMs: ws.data.clientOffsetMs, message: parsedFrame, serverTs: Date.now() })`.
4. Subscribe Gateway to `bridge.onGatewayEvent`:
   - `broadcast_to_room`: sends payload JSON to all sockets in room via `clientManager.getRoomSockets()`.
   - `send_to_client`: sends payload JSON to specific socket via `clientManager.getSocket(playerId)`.
   - `disconnect_client`: closes client socket.
   - `player_room_assigned`: updates `clientManager.assignRoom(playerId, roomCode)` and `ws.data.roomCode = roomCode`.
   - `player_room_cleared`: updates `clientManager.clearRoom(playerId, roomCode)` and `ws.data.roomCode = null`.
5. Create `apps/gateway/src/bridge/loopback-client.ts`:
   - `LoopbackIpcClient` implementing `EventBridge`:
     - Connects to `ws://${env.ENGINE_HOST}:${env.ENGINE_PORT}` with auto-reconnect backoff.
     - Routes outbound `publishToEngine` frames over loopback socket.
     - Receives `EngineToGatewayEvent` frames and dispatches to registered handlers.
</action>
