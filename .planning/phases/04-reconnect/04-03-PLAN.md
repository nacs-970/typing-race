<objective>
Implement room lifecycle management to prevent server resource leaks: 60s idle room sweeper (10 min eviction), WS heartbeat ping/pong (15s ping / 5s timeout), and in-memory per-IP rate limiting (10 room creations/hour).

Purpose: Fulfill REQ-09 success criteria 3, 4, and 5 (idle room sweeper, heartbeat ping/pong, per-IP rate limiting).
</objective>

<tasks>

### Task 1: 60s idle room sweeper
- In `apps/server/src/rooms/manager.ts`:
  - Add `sweepIdleRooms(maxIdleMs?: number, now?: number): number`:
    - Iterate `rooms.values()`.
    - If `now - room.lastActivityAt > (maxIdleMs ?? 600_000)`:
      - Close remaining client WebSockets cleanly with close code 1000 ("Room closed due to inactivity").
      - Delete room from `rooms` map.
    - Return number of evicted rooms.
- In `apps/server/src/index.ts`:
  - Run `sweepIdleRooms` every 60,000ms.
- Write unit tests in `apps/server/src/__tests__/sweeper.test.ts`:
  - Verify rooms idle <10 min are preserved.
  - Verify rooms idle >10 min are removed and sockets closed.

### Task 2: WS heartbeat ping/pong
- In `apps/server/src/index.ts` & `apps/server/src/ws/handlers.ts`:
  - Configure Bun WebSocket heartbeat:
    - Track `ws.data.lastPongAt = Date.now()`.
    - Every 15s, send ping to active sockets.
    - If `now - ws.data.lastPongAt > 20_000` (15s + 5s timeout), terminate dead socket via `ws.terminate()`.
    - Handle `pong(ws)` to update `ws.data.lastPongAt = Date.now()`.

### Task 3: In-memory per-IP rate limiter
- In `apps/server/src/rooms/manager.ts`:
  - Create `class IpRateLimiter`:
    - Sliding window or token bucket: max 10 creations per IP per 3600s (1 hour).
    - Method `checkAndConsume(ip: string): boolean`.
    - Auto-cleans expired entries to prevent memory buildup.
- In `apps/server/src/ws/dispatch.ts`:
  - In `case "create_room"`:
    - Extract client IP from `ws.data` (e.g. `ws.remoteAddress`).
    - If `rateLimiter.checkAndConsume(ip)` returns false:
      - Send error `{ type: "error", code: "RATE_LIMITED", message: "Too many rooms created from this IP. Limit is 10 per hour." }`.
      - Return early.
- Write unit tests in `apps/server/src/__tests__/rate-limit.test.ts`:
  - Verify 10 creations allowed, 11th rejected.
  - Verify independent IP limits.
  - Verify reset after 1 hour.
</tasks>
