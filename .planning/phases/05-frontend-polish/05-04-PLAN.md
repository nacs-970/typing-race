<threat_model>
ASVS Level 1 Threat Model:
1. Threat: Cross-Site Scripting (XSS) in toast notifications or results board through maliciously formatted player names or error strings.
   - Severity: High (Mitigated).
   - Mitigation: All dynamic values (player nicknames, error descriptions, delta times) are rendered via standard React JSX text interpolation. React automatically escapes HTML entities, preventing script injection. No `dangerouslySetInnerHTML` is used anywhere in HUD or results components.
2. Threat: Client-side score forgery on the Results Board.
   - Severity: High (Mitigated).
   - Mitigation: Results displayed in `ResultsBoard` are derived exclusively from the authoritative `race_end.results` frame emitted by the server (`PlayerFinalStats[]`). The client only sorts and formats deltas; it cannot alter finish times or WPM values.
3. Threat: Notification spam / DOM memory leak from rapid reconnect/disconnect events.
   - Severity: Low (Mitigated).
   - Mitigation: `ToastQueue` limits active toasts to a maximum of 5. Older toasts are automatically evicted, and toasts with identical error keys are deduplicated.
</threat_model>
