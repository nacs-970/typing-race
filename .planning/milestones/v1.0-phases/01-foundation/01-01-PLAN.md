# Phase 1 — Plan 01: Monorepo + Wire Contract + Hello-World Tracer

<objective>
Stand up the bun-workspace monorepo skeleton with a shared `@typing-race/shared` package exporting Zod 4 discriminated unions for the wire contract (REQ-13), a `@typing-race/server` Bun+Hono skeleton with a working `/health` route and a `/ws` endpoint that emits a Zod-validated `hello` frame, and a `@typing-race/web` Vite+React skeleton rendering a "Hello Typing Race" page. After this plan, the tracer (a single end-to-end slice) is proven: `bun install` succeeds, both dev servers boot, the browser SPA opens a WebSocket through the Vite proxy, receives a typed `hello` frame from the server, and displays `playerId` in the DOM.

Purpose: This is the thinnest possible vertical slice through every layer the phase will modify. The shared Zod schemas, the Bun-native WS upgrade, the Hono HTTP routing, the Vite dev proxy, and the React store all exist and are wired together end-to-end. Every subsequent plan expands out from this proven skeleton rather than re-architecting.

Output:
- Bun-workspace monorepo: root `package.json`, `tsconfig.base.json`, `.gitignore`, `bunfig.toml`, lint/format config
- `@typing-race/shared`: Zod 4 schemas for initial wire frames (`hello`, `pong`, `ping`, `join_room`, `leave_room`, `error`); barrel `src/index.ts`; stub `race.ts` (types only) and `codes.ts` (alphabet constant)
- `@typing-race/server`: Bun.serve with Hono `/health`, native WS `/ws` endpoint, typed `ws.data`, pino logger stub
- `@typing-race/web`: Vite 8 + React 19 + Zustand 5 SPA, "Hello Typing Race" page, `WsConnection` class with Zod-validated inbound parsing
</objective>
