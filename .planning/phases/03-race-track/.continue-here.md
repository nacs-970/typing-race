## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Hand-edit without commit | File modified outside of git workflow (e.g., user's editor, auto-save) — gets served by Vite HMR but the breakage is invisible to git status until checked | blocking | Run `git status --short` and `git diff <file>` BEFORE every resume. If the diff contains debug noise (`console.log`), commented-out critical calls (`onCorrection`, `ev.preventDefault`), or reverts of recently-applied fixes, discard via `git checkout`. |
| `if (ev.key.length !== 1) return;` | Drops Backspace, Delete, Spacebar (in some browsers), all function keys, IME composition events | blocking | Per `realtime-input-sync` skill: handle Backspace and Spacebar EXPLICITLY before the length check. |
