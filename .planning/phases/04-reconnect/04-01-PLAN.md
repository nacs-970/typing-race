<objective>
Introduce sessionToken generation on room creation/join, add the `rejoin_room` wire schema, and implement the server-side re-binding mechanism where an inbound WebSocket connection can reclaim an existing Player slot using its sessionToken.

Purpose: Foundation for REQ-07 (mid-race reconnect). Enables players who disconnect to re-identify themselves to the server and re-bind their active WebSocket.
</objective>

<tasks>

### Task 1: Wire schemas & domain types for sessionToken and rejoin_room
- Extend `joinedRoomSchema` in `packages/shared/src/messages.ts` with `sessionToken: z.string().uuid()`.
- Add `rejoinRoomSchema = z.object({ type: z.literal("rejoin_room"), roomCode: z.string().length(6), sessionToken: z.string().uuid() })` to `clientToServerSchema`.
- Add `sessionToken: string` to `Player` interface in `apps/server/src/race/types.ts`.
- Update `broadcastJoinedRoom` in `apps/server/src/ws/broadcast.ts` to include `sessionToken: target.sessionToken`.

### Task 2: Server sessionToken generation and player re-binding logic
- In `apps/server/src/rooms/manager.ts`:
  - Update `addPlayer` to generate `sessionToken: crypto.randomUUID()`.
  - Add helper `findPlayerBySessionToken(code: string, sessionToken: string): Player | null`.
  - Add helper `rebindPlayerSocket(room: Room, player: Player, newWs: WsRef): void` that updates `player.wsRef = newWs`, sets `newWs.data.playerId = player.playerId`, `newWs.data.roomCode = room.code`, `newWs.data.sessionToken = player.sessionToken`.

### Task 3: Inbound `rejoin_room` dispatch & unit tests
- In `apps/server/src/ws/dispatch.ts`:
  - Add `case "rejoin_room"`:
    - Look up room by `msg.roomCode`. If missing, reply with `ROOM_NOT_FOUND`.
    - Look up player by `findPlayerBySessionToken`. If missing, reply with `SESSION_INVALID`.
    - Rebind player socket via `rebindPlayerSocket`.
- Create `apps/server/src/__tests__/reconnect.test.ts`:
  - Test sessionToken generation on `addPlayer`.
  - Test `findPlayerBySessionToken` with valid and invalid tokens.
  - Test socket rebinding on `rejoin_room`.
</tasks>
