## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → WS → dispatch.start_race (no passageId) | Server auto-deals; client cannot inject a specific passageId they want to game the no-repeat rule |
| Server tick() → grace_countdown broadcast | Server-side state, no untrusted input |

| Browser → ResultsBoard → ws.send(start_race rematch) | Host-only button (UI gate); server also enforces hostId check in dispatch (Phase 2 invariant) |
| Browser → cursor_update charStates/wpm rendering | Server-authoritative; clients render-only (Plan 02 mitigation) |
