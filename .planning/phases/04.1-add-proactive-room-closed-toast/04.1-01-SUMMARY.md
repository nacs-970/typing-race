# Phase 04.1 Plan 01: Add proactive room-closed toast Summary

**Added a proactive notification, fired when a room's second-to-last player leaves, reaching the one remaining player — not only reactively on that client's next failed action. Retargeted from an initial `size===0` attempt that a re-verification pass proved has zero real recipients, to `size===1`, which does.**

## Accomplishments
- `RoomManager.removePlayer()` (apps/engine/src/rooms/manager.ts) publishes a `broadcast_to_room` event with `{type: "error", code: "ROOM_CLOSED", ...}` at the `room.players.size === 1` transition (retargeted from an initial, practically-unreachable `size === 0` attempt).
- Publish ordering confirmed correct: fires AFTER the leaver's own `player_room_cleared` publish, so the leaver's own socket (already untracked on the gateway side by then) never receives its own room's notice.
- `apps/web/src/App.tsx` maps the `ROOM_CLOSED` error code to an "Alone in Room" / "All other players have left this room." toast — copy corrected to match the actual size===1 semantics (the room is not closed; the recipient is the one still in it).
- Two engine-level regression tests (`rooms.test.ts` #9, #9b) plus a real two-socket integration test extending the existing full-race-flow test in `apps/gateway/src/__tests__/gateway.test.ts` — the latter proves actual delivery over real WebSocket connections, not just bridge-event emission.
- Full verify chain green: typecheck clean, 153/153 backend tests, 84/84 web tests.

## Decisions Made
- See key-decisions above. The retarget was found by a re-verification pass building a real harness (RoomManager + ClientManager + bindBridgeToGateway) rather than trusting the initial commit's passing-but-shallow bridge-event-only test.

## Deviations from Plan
- 04.1-CONTEXT.md's original plan assumed `size===0` was the correct trigger (matching the "room becomes empty" framing of the diagnosed gap). Re-verification found this has no real recipient in this project's architecture (no spectator/multi-viewer concept beyond `room.players`), and retargeted to `size===1`.
