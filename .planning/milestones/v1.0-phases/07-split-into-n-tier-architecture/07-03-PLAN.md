<threat_model>
ASVS Level 1 Threat Model:
1. Threat: Container breakout or execution with escalated root privileges.
   - Severity: High (Mitigated).
   - Mitigation: All Dockerfiles enforce non-root user execution (`USER bun` or non-root web server user).
2. Threat: Cascading container startup failures or race conditions in docker-compose.
   - Severity: Medium (Mitigated).
   - Mitigation: `docker-compose.yml` utilizes healthcheck conditions (`condition: service_healthy`) for Redis and Gateway, ensuring dependencies are fully operational before dependent services begin ingesting traffic.
3. Threat: Secret or credential exposure in container build stages.
   - Severity: Medium (Mitigated).
   - Mitigation: Multi-stage builds isolate build tools and omit secrets, using `.dockerignore` to prevent copying `.env`, `.git`, or temporary files into images.
</threat_model>
