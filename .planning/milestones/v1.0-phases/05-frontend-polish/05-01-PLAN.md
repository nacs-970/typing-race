<threat_model>
ASVS Level 1 Threat Model:
1. Threat: Client-side tampering with WPM or keystroke timestamps in TypingEngine to artificially inflate scores.
   - Severity: High (Mitigated).
   - Mitigation: Server remains the sole authoritative source of truth for keystroke validation, anti-cheat rate limiting (min 20ms interval), and final official WPM/accuracy computation. Client-side TypingEngine calculations are purely optimistic for local HUD rendering.
2. Threat: Denial of Service / Memory leak via unbounded snapshot accumulation in CursorManager ring buffer.
   - Severity: High (Mitigated).
   - Mitigation: CursorManager hard-caps each player's snapshot ring buffer to 10 entries (sliding window). Disconnected or removed players have their buffers deleted immediately via `removePlayer()`.
3. Threat: Session token hijacking / credential replay in RaceClient.
   - Severity: Medium (Mitigated).
   - Mitigation: Session tokens are stored in `SameSite=Lax`, `path=/` cookies with 24-hour expiration, validated as RFC4122 UUID v4 strings before being transmitted over WebSocket.
</threat_model>

1. Define and export interface `TypingEngineEvents`:
   - `keystroke: (index: number, char: string, clientTs: number) => void`
   - `correction: (backspaces: number, clientTs: number) => void`
   - `stats_updated: (stats: { rawWpm: number; netWpm: number; accuracy: number; uncorrectedErrors: number }) => void`
   - `finished: (finishTimeMs: number) => void`
2. Define and export class `TypingEngine`:
   - State properties: `passageText: string`, `ownIndex: number`, `charStates: CharState[]`, `totalKeystrokes: number`, `startTimeMs: number | null`, `listeners: Map<keyof TypingEngineEvents, Set<Function>>`.
   - Method `init(passageText: string): void`: resets state, fills `charStates` with `"pending"` array of length `passageText.length`.
   - Method `handleKeyDown(ev: KeyboardEvent): boolean`:
     - Discards event if `ev.ctrlKey || ev.metaKey || ev.altKey`.
     - Handles `"Backspace"`: if `ownIndex > 0`, decrements `ownIndex`, sets `charStates[ownIndex] = "pending"`, emits `"correction"` with count 1, calls `updateStats()`, returns `true`.
     - Handles single character keys (`ch.length === 1`, normalizes `"Spacebar"` to `" "`): checks bounds against `passageText.length`; records `startTimeMs = Date.now()` on first keystroke; increments `totalKeystrokes`; matches `ch === passageText[ownIndex]` to assign `"correct"` or `"error"` into `charStates[ownIndex]`; increments `ownIndex`; emits `"keystroke"`; calls `updateStats()`; if `ownIndex === passageText.length`, emits `"finished"`; returns `true`.
   - Method `subscribe<K extends keyof TypingEngineEvents>(event: K, handler: TypingEngineEvents[K]): () => void`: registers listener and returns unsubscribe function.
   - Method `updateStats(now: number): void`: calculates elapsed minutes, counts correct and uncorrected errors across `charStates[0..ownIndex-1]`, computes `rawWpm = (totalKeystrokes / 5) / elapsedMinutes`, `netWpm = Math.max(0, (correctChars / 5 - uncorrectedErrors / 5) / elapsedMinutes)`, and `accuracy = totalKeystrokes > 0 ? correctChars / totalKeystrokes : 1` mirroring `apps/server/src/race/scoring.ts:98-143`. Emits `"stats_updated"`.
   - Getters: `getOwnIndex(): number`, `getCharStates(): readonly CharState[]`, `getPassageText(): string`.
3. Create `apps/web/src/__tests__/typing-engine.test.ts`:
   - Test keystroke advancement and correct/error charState assignment.
   - Test backspace decrements `ownIndex` and resets charState to `"pending"`.
   - Test WPM scoring formulas produce identical values to server scoring.
   - Test completion triggers `"finished"` event when reaching passage length.
</action>

### Task 2: Headless CursorManager with 100ms Snapshot Buffer & Clamped Interpolation (D-03, D-04, REQ-06)

<action>
Create `apps/web/src/core/cursor-manager.ts` per D-03:
1. Export constants `BUFFER_MS = 100` and `MAX_EXTRAPOLATE_MS = 150`.
2. Export interface `CursorSnapshot { index: number; receivedAt: number; }`.
3. Export class `CursorManager`:
   - Private properties: `buffers: Map<string, CursorSnapshot[]>`, `playerColors: Map<string, string>`, `playerNicknames: Map<string, string>`, `localProgress: number`.
   - Method `registerPlayer(playerId: string, nickname: string, color: string): void`: initializes empty snapshot buffer and stores player metadata.
   - Method `removePlayer(playerId: string): void`: cleans up player buffer and metadata.
   - Method `onCursorUpdate(playerId: string, index: number, localTime?: number): void`:
     - Retrieves player buffer; returns early if player not registered.
     - Detects backspace rewind ($index < lastSnapshot.index$): if detected, clears previous snapshots (`buf.length = 0`) to immediately snap without backward lerping.
     - Appends `{ index, receivedAt: localTime ?? performance.now() }`.
     - Caps buffer at 10 items (`if (buf.length > 10) buf.shift()`).
   - Method `calculateInterpolatedIndex(playerId: string, now: number): number`:
     - Computes `targetTime = now - BUFFER_MS`.
     - If buffer has 0 snapshots, returns 0.
     - If buffer has 1 snapshot, returns `buf[0].index`.
     - If `targetTime <= buf[0].receivedAt`, returns `buf[0].index`.
     - If `targetTime >= buf[buf.length - 1].receivedAt`:
       - Computes `dt = targetTime - last.receivedAt`.
       - If `dt <= MAX_EXTRAPOLATE_MS` and `buf.length >= 2`: computes typing rate `(last.index - prev.index) / Math.max(1, last.receivedAt - prev.receivedAt)` and returns `last.index + rate * dt`.
       - If `dt > MAX_EXTRAPOLATE_MS`: clamps and returns `last.index`.
     - If `targetTime` falls between snapshots: finds `s0` and `s1`, calculates linear interpolation factor `alpha = (targetTime - s0.receivedAt) / (s1.receivedAt - s0.receivedAt)`, and returns `s0.index + alpha * (s1.index - s0.index)`.
   - Method `setLocalProgress(index: number): void`: updates local player's unbuffered progress index.
4. Create `apps/web/src/__tests__/cursor-manager.test.ts`:
   - Test snapshot insertion and sliding buffer cap of 10 items.
   - Test linear lerp interpolation at midpoint ($targetTime = s0 + 50ms$).
   - Test forward extrapolation with constant velocity for $dt \le 150ms$.
   - Test extrapolation clamp for $dt > 150ms$ freezes at last snapshot index.
   - Test backspace rewind immediately clears buffer and snaps without backward lerp.
</action>
